# 校内LAN 起動手順（Phase 4）

## 1. 初回だけ

このフォルダで次を実行します。

```bash
npm install
```

## 2. 毎日の起動

```bash
npm start
```

既定では `8080` 番ポートで、校内LAN向けに `0.0.0.0` で待ち受けます。

担任PC自身では次を開きます。

- 児童画面: `http://localhost:8080/`
- 担任画面: `http://localhost:8080/teacher.html`

児童タブレットでは、担任PCのIPv4アドレスを使います。

例: 担任PCが `192.168.1.50` の場合

- `http://192.168.1.50:8080/`

## 3. 現在実装されている通信

- `GET /api/health` : サーバー稼働確認
- `GET /api/time` : 教室共通時計の基準時刻
- `GET /api/classes/:classId/today` : 起動・再接続時に最新の朝設定を取得
- `POST /api/classes/:classId/config` : 担任が朝設定を保存・配信
- `WS /ws?classId=1-1` : 設定変更を児童端末へリアルタイム配信

担任が「クラスに反映」を押すと、サーバー上の学級設定JSONを更新し、接続中の同じ学級の児童端末へWebSocketで通知します。

## 4. 通信が切れた場合

児童画面は直前の設定をブラウザのLocalStorageにも保持します。サーバーへ接続できない場合でも直前の朝タスクを表示し、WebSocketは3秒後から自動再接続します。

担任画面もサーバーへ送信できなかった場合は、このPC内に設定を保存したことを明示します。

## 5. Windows Defender ファイアウォール

学校の管理方針に従い、必要な場合のみTCP 8080番への受信を「ドメイン／プライベート」ネットワークに限定して許可してください。管理者権限や校内情報担当者の承認が必要な環境では、個人判断で設定変更しないでください。

## 6. データ保存

サーバーは起動時に次を自動作成します。

```text
server/data/classes/
```

学級ごとの朝タスク設定を `1-1.json` のように保存します。

このPhaseでは、心の天気など児童個人の情報はサーバー保存対象にしていません。個人情報を含むデータ設計は別フェーズで保存期間・閲覧権限を決めてから実装します。

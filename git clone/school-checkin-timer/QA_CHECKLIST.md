# 朝のチェックイン / QAチェックリスト

## 目的
実機確認では、機能の成否だけでなく「朝の教室で迷わず使えるか」「見た目が子どもを引きつけるか」を優先して確認する。

## 1. 児童画面・低学年モード
- [ ] 1366×768で時計、心の天気、朝の準備、タイマーが1画面で把握できる
- [ ] 1024×768で主要UIが無理なく収まる
- [ ] 768×1024の縦向きタブレットでカードが崩れない
- [ ] 375px幅で横スクロールが発生しない
- [ ] 心の天気4ボタンが指で押しやすい
- [ ] タスク完了のチェックが分かりやすい
- [ ] 全タスク完了時にマスコットの達成演出が表示される
- [ ] アニメーションを減らすOS設定でも操作できる

## 2. 児童画面・高学年モード
- [ ] 担任画面で高学年に切り替えると配色・密度・文言が落ち着いた表示に変わる
- [ ] タスクが一覧形式になり、残り時間と進捗を同時に見渡せる
- [ ] 任意の一言メモ欄が表示される
- [ ] 一言メモを書かなくてもチェックインできる
- [ ] メモは他の児童端末に表示されない

## 3. 時計・タイマー
- [ ] 現在時刻が1秒ごとに更新される
- [ ] アナログ時計とデジタル時計の時刻が一致する
- [ ] `/api/time` 利用時にサーバー時刻へ補正される
- [ ] 開始前・活動中・終了後の表示が正しい
- [ ] 担任が開始/終了時刻を変更すると児童画面へ反映される

## 4. 端末初期設定
- [ ] 初回アクセスで `setup.html` へ誘導される
- [ ] 学年・組・出席番号を保存できる
- [ ] 翌回起動で再入力不要
- [ ] 児童画面下部に正しい学級・番号が表示される
- [ ] 「設定」から変更できる

## 5. 担任タスク編集
- [ ] 項目追加・削除・ON/OFFができる
- [ ] 上下移動で順序を変更できる
- [ ] アイコン・名称・目安時間を変更できる
- [ ] 通常日・月曜日・雨の日・集会の日テンプレートを切り替えられる
- [ ] 児童プレビューが編集に追従する
- [ ] 「クラスに反映」後に設定バージョンが上がる

## 6. 校内LAN同期
- [ ] 担任PCで `npm install` → `npm start` が成功する
- [ ] `http://localhost:8080/teacher.html` が開く
- [ ] 同一LANの別端末から `http://<担任PC-IP>:8080/` が開く
- [ ] 担任の変更が再読み込みなしで児童端末へ届く
- [ ] 10台以上を同時接続しても操作に大きな遅延がない
- [ ] WebSocket切断後に自動再接続する
- [ ] 再接続時に最新設定を取り直す

## 7. 配信確認
- [ ] 担任画面で接続台数が表示される
- [ ] 各端末の設定受信ACKが表示される
- [ ] 最新設定未受信端末が「反映待ち」で分かる
- [ ] 同一端末の再接続で二重表示にならない

## 8. 心の天気・担任ダッシュボード
- [ ] 心の天気が担任ダッシュボードへ反映される
- [ ] 朝の準備進捗が `完了数/総数` で表示される
- [ ] 雨・かみなりを強い警告色で表示しない
- [ ] 一言メモは担任画面だけに表示される
- [ ] 出席番号順に児童カードが並ぶ
- [ ] オフライン端末が静かに区別される

## 9. 障害時
- [ ] Wi-Fiを切っても直前の朝タスクを操作できる
- [ ] 通信障害時に子ども向けの難しいエラー文を出さない
- [ ] Wi-Fi復帰後に自動同期する
- [ ] サーバー停止中も担任PC内のLocalStorage保存が機能する

## 10. 見た目の最終確認
- [ ] マスコットが大きすぎて操作情報を圧迫していない
- [ ] 低学年は「楽しい」、高学年は「幼すぎない」印象になっている
- [ ] 時計が常に見つけやすい
- [ ] 「今やること」が視線移動なしで分かる
- [ ] 色だけに頼らず、文字・形でも状態を判別できる
- [ ] 教員画面は情報量が多くても圧迫感がない

# 朝のチェックイン / 最終QAチェックリスト

## 目的
完成前の実機確認では、機能の成否だけでなく「朝の教室で迷わず使えるか」「見た目が子どもを引きつけるか」「出席・健康・心の天気を混同しないか」を優先して確認する。

## 1. 児童画面・低学年モード
- [ ] 1366×768で時計、心の天気、朝の準備、タイマーが1画面で把握できる
- [ ] 1024×768で主要UIが無理なく収まる
- [ ] 768×1024の縦向きiPadでカードが崩れない
- [ ] 375px幅で横スクロールが発生しない
- [ ] 心の天気4ボタンが大きく、指で押しやすい
- [ ] 天気アイコンと「はれ・くもり・あめ・かみなり」の文字が十分大きい
- [ ] 朝の準備5種SVG（連絡帳・机・読書・検温・提出物）が正常表示される
- [ ] イラスト・タスク名・所要時間・チェックマークが重ならない
- [ ] 5項目以上に増やしても天気・文字・タスクカードが極端に縮小しない
- [ ] タスク完了のチェックが分かりやすい
- [ ] 心の天気と全タスク終了後に「おわり」が有効になる
- [ ] 完了時にマスコットの達成演出が表示される
- [ ] 基本語句がひらがな中心になっている
- [ ] 現在時刻は1〜12が読める大きなアナログ時計で表示される

## 2. 児童画面・高学年モード
- [ ] 担任設定で高学年に切り替えると配色・密度・文言が落ち着いた表示に変わる
- [ ] 768×1024 / 375pxでも一覧性を失わない
- [ ] 現在時刻はデジタル時計で素早く把握できる
- [ ] 任意の一言メモ欄が表示される
- [ ] 一言メモを書かなくてもチェックインできる
- [ ] メモは他の児童端末に表示されない
- [ ] 日常的な学校用語は漢字混じり表記になっている
- [ ] 心の天気と全タスク終了後に「終了」が有効になる

## 3. 学年・学級・表示設定
- [ ] 担任側の初期設定で低学年 / 高学年を選べる
- [ ] 実際の児童画面には「低学年」「高学年」ではなく学年・組が表示される
- [ ] 同じタスクに低学年用 `label` と高学年用 `labelHigh` を設定できる
- [ ] 天気表示が低学年「はれ・くもり・あめ・かみなり」、高学年「晴れ・曇り・雨・雷」になる
- [ ] 低学年はアナログ時計、高学年はデジタル時計になる
- [ ] 担任プレビューで低学年 / 高学年を独立確認できる
- [ ] プレビュー切替で実際の配信設定が勝手に変わらない

## 4. 端末導入・iPad / Android
- [ ] 原則ブラウザ利用でインストール不要の運用ができる
- [ ] iPad Safariから校内LAN URLを開ける
- [ ] Android Chromeから校内LAN URLを開ける
- [ ] PWAは学校のMDMで許可されている場合だけ選択できる説明になっている
- [ ] Webページ単独でSafari / Chromeを強制起動できないことが明記されている
- [ ] 指定利用時間帯を担任側で設定できる
- [ ] 切断時に自動再接続する
- [ ] 一時切断中も直前画面を継続できる
- [ ] インターネット接続なしでも校内LAN内で基本運用できる

## 5. 児童名簿・C4th
- [ ] 出席番号・児童名・端末IDを担任側で登録できる
- [ ] 1〜30番 / 1〜35番のひな型を簡単に作れる
- [ ] C4thから書き出したCSVを選択できる
- [ ] CSVは外部クラウドへ送信せずブラウザ内で解析する
- [ ] 列対応と学年・組を確認してから反映できる
- [ ] C4th仕様差異がある場合は推測で自動確定せず確認できる
- [ ] 児童名は児童同士の画面には表示しない
- [ ] C4thへ戻すための出席簿出力設計を壊していない

## 6. 今日の出席・健康観察
- [ ] 朝のチェックイン完了児童は出席候補として把握できる
- [ ] 未チェックイン児童を自動で「欠席確定」にしない
- [ ] 欠席・遅刻・早退は担任が確認・修正できる
- [ ] 病欠 / 事故欠など欠席理由を記録できる
- [ ] 健康観察は「健康○ / 要観察 / 保健室 / 体調不良 / その他」を記録できる
- [ ] 健康メモを担任が入力できる
- [ ] 未確認児童が残る場合は日次確認を確定できない
- [ ] 確認済みにした日付と時刻が記録される

## 7. 出席・健康・心の天気の分離
- [ ] 出席状態を変更しても心の天気を上書きしない
- [ ] 健康状態を変更しても心の天気を上書きしない
- [ ] 心の天気を変更しても出席・健康記録を上書きしない
- [ ] 心の天気は診断・評価・順位付けとして扱わない
- [ ] 雨・かみなりを欠席や健康不良へ自動変換しない
- [ ] 一言メモは心の天気側の文脈として保持し、健康メモと混在しない

## 8. 月間出席簿
- [ ] 児童ごとの横合計が表示される
- [ ] 日ごとの縦合計が表示される
- [ ] 出席・欠席・遅刻・早退・病欠・事故欠を月単位で集計できる
- [ ] 欠席理由の合計が確認できる
- [ ] 月合計・総合計が確認できる
- [ ] 健康観察の月間集計が確認できる
- [ ] 授業日カレンダーの休業日を出席対象日として数えない
- [ ] 1024 / 768 / 375pxで表・操作部が崩れない

## 9. 学期・年度集計
- [ ] 1学期・2学期・3学期の集計が表示される
- [ ] 年度総合計が表示される
- [ ] 出席・欠席・遅刻・早退・病欠・事故欠を集計できる
- [ ] 健康○ / 要観察 / 保健室 / 体調不良 / その他を学期・年度で集計できる
- [ ] 学期開始日・終了日は学校ごとに設定できる
- [ ] 学期設定変更後も過去データを壊さない

## 10. 授業日カレンダー
- [ ] 土日が既定で休業日になる
- [ ] 振替休業日・学校行事・特別日を担任が設定できる
- [ ] C4th等から学校暦を得られる場合に取り込む余地を残している
- [ ] 授業日 / 休業日 / 特別日の区別が月間出席簿へ反映される
- [ ] 375pxでも日付・理由・操作が読める

## 11. 心の天気ダッシュボード
- [ ] 今日の心の天気が担任ダッシュボードへ反映される
- [ ] 朝の準備進捗が `完了数/総数` で表示される
- [ ] 一言メモは担任画面だけに表示される
- [ ] 出席番号順に児童カードが並ぶ
- [ ] オフライン端末が静かに区別される
- [ ] 月〜金の曜日別傾向が確認できる
- [ ] 月別集計が確認できる
- [ ] 4月〜翌3月の年度推移が確認できる
- [ ] 梅雨・運動会・学期末など学校行事・季節メモを月別に保存できる
- [ ] 行事メモは別の担任PC / ブラウザからも同じ学級で共有できる
- [ ] 雨・かみなりを強い警告色や診断ラベルで扱わない

## 12. 担任ホーム・簡単運用
- [ ] 「毎朝使う」「記録を見る」「設定する」が視覚的に分離されている
- [ ] 初期設定後は設定欄を閉じたまま日常運用できる
- [ ] 今日の出席・健康へすぐ移動できる
- [ ] 心の天気・教室のようすへすぐ移動できる
- [ ] 月間・学期年度集計へ迷わず移動できる
- [ ] 設定変更は必要時だけ開けばよい
- [ ] 375pxでホームカード・設定折りたたみ・固定反映バーが重ならない

## 13. 校内LAN同期
- [ ] 担任PCで `npm install` → `npm start` が成功する
- [ ] `http://localhost:8080/teacher.html` が開く
- [ ] 同一LANのiPad / Androidから `http://<担任PC-IP>:8080/` が開く
- [ ] 担任の変更が再読み込みなしで児童端末へ届く
- [ ] 10台以上を同時接続しても大きな遅延がない
- [ ] WebSocket切断後に自動再接続する
- [ ] 再接続時に最新設定を取り直す
- [ ] 同一端末の再接続で二重表示にならない
- [ ] 各端末の設定受信ACKが担任側で確認できる

## 14. 障害時・保存復帰
- [ ] Wi-Fiを切っても直前の朝タスクを操作できる
- [ ] 通信障害時に子ども向けの難しいエラー文を出さない
- [ ] Wi-Fi復帰後に自動同期する
- [ ] 学級設定はサーバー側へ保存される
- [ ] 心の天気履歴は履歴データとして保存される
- [ ] 出席・健康・カレンダー・学期設定は出席データ系として保存される
- [ ] サーバー再起動後も保存済みデータを読み戻せる

- [ ] 生成スクリーンショットを最終目視する

## 16. 見た目の最終確認
- [ ] マスコットが大きすぎて操作情報を圧迫していない
- [ ] 低学年は「楽しい」、高学年は「幼すぎない」印象になっている
- [ ] 低学年の心の天気が画面内で十分な存在感を持つ
- [ ] 時計が常に見つけやすい
- [ ] 「今やること」が視線移動なしで分かる
- [ ] 色だけに頼らず、文字・形でも状態を判別できる
- [ ] 教員画面は情報量が多くても圧迫感がない
- [ ] 担任画面のプレビューだけで学年差を判断できる

## 17. 学校導入前の確認
- [ ] Windows Defender FirewallのTCP 8080許可が学校方針に合う
- [ ] iPad / AndroidのMDM制限を確認する
- [ ] 校内Wi-Fiで端末間通信が許可されている
- [ ] 個人情報・健康情報の保存期間と閲覧権限を学校方針で確認する
- [ ] C4th CSV入出力の実際の列仕様を対象校データで確認する
- [ ] 実在児童データを使う前にテスト用名簿で一通り検証する

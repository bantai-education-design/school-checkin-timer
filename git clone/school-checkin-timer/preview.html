SCHOOL CHECK-IN TIMER

実装画面プレビュー

先生が毎朝迷わず使えることを優先して、現在の主要画面をまとめました。

確認用入口です。実際の出席・同期データは校内サーバー起動時に接続します。ここでは画面構成と導線を確認できます。
担任ホーム今日の朝を整える

「毎朝使う」「記録を見る」「設定する」を分離。初期設定後は毎日の操作を前面に出します。

毎朝今日の出席・健康観察

チェックインをもとに出席を確認し、担任が健康状態・遅刻・早退・欠席理由を記録します。

心の天気教室のようす

今日の心の天気に加え、月〜金、月別、年度別、学校行事・季節との変化を見ます。

記録月間出席簿

児童別横合計・日別縦合計・欠席理由・健康観察を月単位でまとめます。

記録学期・年度集計

1・2・3学期と年度総合計をまとめ、出席と健康観察を同じ流れで確認します。

設定学期設定

学校ごとの学期開始日・終了日を設定。標準値から必要なところだけ変更できます。

※ 心の天気は診断・評価・順位付けを目的とせず、担任が声をかける手がかりとして扱う設計です。児童名や出席情報を公開プレビュー用データとして外部送信する設計にはしていません。
